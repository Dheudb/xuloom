# 开始任务前：能力、数据与验收

Xuloom 提供通用执行框架；模型连接成功、工具执行成功与任务正确是三件事。以下任务可以沿用内置 Skills，不需要额外调度器，也不会自动把科研方法写进框架。

| 你要完成的工作 | 现有入口 | 开始前确认 | 完成时检查 |
| --- | --- | --- | --- |
| 阅读论文、总结资料 | `document-summary`、`web-research` | 文件可读、全文是否拿到、当前模型是否支持图像；扫描 PDF 需页图 | 页码、来源和缺失内容；摘要不能冒充全文 |
| 分析表格、实验数据 | `data-analysis` | 输入格式、列含义、缺失值、本机解析库 | 计算过程、输出表与原数据对应关系、独立回读 |
| 撰写文档 | `document-writing` | 目标格式、字体/渲染工具、输出位置 | 回读正文；涉及排版时生成并检查预览 |
| 设计研究或实验 | `experiment-design` | 研究约束、证据、待检验假设 | 区分模型建议、程序检查和领域专家确认 |
| 修改代码 | `code-development`、`code-review` | 项目规则、依赖、可执行的测试 | 实际测试结果、差异和未验证路径 |

可以直接输入“使用 document-summary，总结这份资料，列出缺失页和证据来源”等自然任务。桌面的 Skills 面板或输入 `$` 可选择相应技能；不需要先学会 MCP、子代理或 Scaling。

“设置与模型 → 任务准备”会检查保存的模型配置、当前 Python 环境的 PDF/Word/Excel/PowerPoint 解析库、办公预览命令和外部 agent 命令。检查不联网、不推理、不自动安装依赖、不输出 Key。找到命令不代表版本或登录已经通过；解析库存在不代表页面渲染或科学结果正确。需要模型时沿用原模型连接页面；需要依赖时由用户选择环境安装。

持续目标可声明 `file_exists`、`file_contains`、`file_sha256`、`json_fields` 和 `csv_columns` 产物检查。JSON 按声明字段和值精确比对，CSV 检查列名、行数和矩形结构；全部保留原工作目录边界与失败记录。不执行任意检查表达式，也不把这些程序检查标成科学正确或人工验收。

## 文件能力的边界

- 文件读取默认最多返回 2000 行，继续位置在返回结果中；读取长单行可用字符分页。版本校验仍会扫描文件计算 SHA，因此不承诺每次分页恒定时间。
- `force=true` 可以重新交付已经读过的原文，适用于上下文压缩后需要核对证据的情况。
- PDF 的 `pages="2"` 只读第 2 页，`"2-5"` 读闭区间，`"2-"` 读到末页。当前模型和端点决定是否使用原生 PDF；其余情况明确以提取文字返回。
- `pdf_mode="image"` 可以向支持图像输入的模型交付最多 10 张选定页图。文本提取为空、截断和缺少图表均明确提示；交付记录不代表模型理解了全部内容，也不是 OCR 验收。
- DOCX/XLSX/PPTX 的忠实编辑取决于本机解析与渲染能力。先做格式预检，修改后回读；没有预览能力时不能宣称版式已核验。

## 数据在哪里，什么时候离开本机

| 数据 | 保存或发送范围 |
| --- | --- |
| API 凭据 | Windows 使用现有 DPAPI 保护；其他平台的可选凭据后端需相应系统支持 |
| 对话、工具输出、读取的原文和产物引用 | 保存在用户数据目录的现有会话与产物存储；并非全部内容默认加密 |
| 发给模型的上下文 | 发送到当前配置的供应商端点；内容可能包含用户消息、文件原文、工具结果与摘要 |
| MCP、浏览器及外部 CLI | 由对应连接/程序处理实际工具请求；安装 Xuloom 不等于获得外部服务账户或免费额度 |
| 远程工作 | 相应任务、回执与产物也可能保存在被选择的远端主机；删除本机会话不等于远端或供应商已删除 |

敏感资料应先检查连接地址、工具权限和保存位置。Windows 工作区系统隔离会禁止网络并禁用尚未接入隔离的 MCP、浏览器等工具；联网研究与该隔离模式不能笼统宣称同时可用。完全访问只沿用当前用户权限，不需要因此修改系统权限。

## 持续目标与蜂群

桌面持续目标可单独设置时间、输出 tokens 和轮数上限，留空则该项不限；恢复和修改目标保留累计用量。它不是精确账单控制，供应商计费与错误用量需另核。

Scaling 的作者数量、请求并发和有效结果数量不同。同一 URL/Key 的本机流控不等于跨机器全局限流；同机原子认领不等于分区期间全局 exactly-once。重试必须确认既有副作用，保留原任务目的、变体、输入版本和重试谱系；已经成功的任务不能通过失败重试入口重做。

Scaling 可选运行级输出准入预算已接入原额度账本，含断连节点的保守预分配，详见 scaling.md；它不等于硬金额或输入加输出总 token 预算。真实千级故障验收不能用队列测试代替。产品保持面向个人，组织 SSO/RBAC、集中审计与企业 DLP 不在本轮范围。

## 本地回归与发布

现有完整 Python、前端及隐藏桌面测试分别运行；单个 Python 测试的诊断截止时间和 CI job 截止时间应保留。GitHub 的自动触发目前仍受原账户账单限制，不会为消除告警而偷偷改为自动付费运行。

资源更新清单绑定源码文件 SHA、Git commit、dirty 标记、构建资源 SHA 和可选测试回执。更新前验证资源与清单；保持同一个 EXE 路径，等应用退出后更新，并保留回退资源。这证明构建来源与字节一致，不替代代码签名、外部模型验收或其他操作系统实测。
