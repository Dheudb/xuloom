# v0.1.5 媒体生成本地验收

范围：fal Queue API 适配器、共享配置与执行、可靠回执、文件产物、桌面音视频播放与 SSH 分块读取。没有调用真实供应商或用户 Key，没有读取、改动或分发私人 Taiyi Skill。此阶段不代表分布式 worker 或外部 Agent 后端完成，完整范围仍见 [持续目标](product-roadmap.md)。

## 验证内容

`tests/test_media_generation.py` 使用实际 loopback HTTP、真实文件系统及原生 QueryEngine 工具执行入口，检查六种媒体用途共用 Key、配置保存与脱敏、权限/Plan 拒绝、目标/Key 在审批期间变化、未知提交结果不重试、跨引擎重启、显式重试必须审批、取消信号与实际完成区别、错误状态/MIME/大小、路径冲突、结果/意图保存故障、子代理所有权、聊天分支与移动、损坏回执，以及正式 CLI 在无聊天 Key 时查询/取消且不请求模型。专门回归 23 项通过；它们返回本地媒体样本，不是真实模型生成质量测试。

`tests/test_remote_ssh.py` 增加真实加密 SSH 中音频信息、范围字节、版本变化拒绝且不请求模型的检查。它运行回环 SSH 服务，不冒充两台物理机器或 POSIX 原生验收。

`desktop/tests/media.e2e.cjs` 使用隐藏 Electron、隔离配置、loopback SSE 与媒体 HTTP 服务，走正式设置、共享 CLI 配置、工具发现/生成、产物来源导航、PNG 解码、WAV 播放、真实 VP8/WebM 解码和播放、原任务直接查询、草稿保留、重启不重发及连接移除。视频样本由测试内 canvas/MediaRecorder 产生，不打包模型、FFmpeg 或额外播放器。文件预览截图用 Playwright 真实页面截图核对；不使用陈旧的后台窗口缓存图作为验收证据。

`desktop/tests/media-preview.test.cjs` 检查范围/suffix/HEAD、撤销后的访问、错误 MIME/版本、远端路径不落回本机。完整远端工作台 E2E 另外从加密 SSH 音频文件读取实际内容、解码元数据，检查没有聊天模型请求。

App/CLI 的任务控制复用现有引擎权限、会话写入锁、工具执行及 busy 状态；没有生成第二次模型 prompt，没有常驻轮询器或第二套任务执行器。供应商请求仅在明确的提交或控制时发生。

## 验证中发现并纠正的问题

- Windows 新发布硬链接的目录缓存 stat 与打开句柄 fstat 的时间字段不一致，导致有效音频被误判为变化。元数据与分块读取改用一致的句柄 stat，专门回归和实际播放验证通过。
- 隐藏 canvas 自动采样可能只生成 WebM 文件头。测试改为明确请求视频帧，后端同时拒绝没有媒体载荷的 WebM/MP4；容器检查不等于所有编码都已验证。
- 任务列表 RPC 尚未返回时测试误把空列表当成最终结果。设置页增加真实加载状态，测试等待加载完成；不靠固定长延迟掩盖异步状态。
- 文件界面旧 E2E 仍断言 `inspectorWidth`，但文件预览早已独立保存 `filePreviewWidth`。修正断言以检查实际字段，并等异步保存完成；保留第一次失败记录。未修改产品去迎合旧字段。
- 供应商确认取消后，旧回执把取消操作也标成失败。现在取消操作成功与生成完成分别报告；App、正式 CLI、重复取消及未产生产物均有回归。
- 带 `..` 或百分号转义的队列地址可能在 HTTP 客户端中归一化到不同 API 路径，现直接拒绝这些队列路径。生成失败的供应商文本同样过滤实际 Key，再返回模型和写入回执；不是只过滤 HTTP 错误。

以上初次失败的日志保留在忽略的 `desktop/build` 中；不把后续通过抹成“从未失败”。
