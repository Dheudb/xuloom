# MCP 市场与搜索

## 市场使用

打开项目，在侧边栏点击 **MCP 市场**。

- **精选目录**：Exa Search、Brave Search、Fetch、Filesystem、GitHub。
- **官方 MCP 注册表**：按用途搜索和加载更多；仅列出可以完整表示启动参数的受支持条目。
- **我的服务**：编辑、测试连接、启用、停用和移除。
- **自定义服务**：添加本地 stdio 程序或远程 Streamable HTTP 地址。

安装只保存配置，新服务默认停用。测试连接会启动本地程序或访问远程服务，
执行握手并发现工具，不执行搜索、不需要模型 API。
启用后下一次任务会连接，也可以点击刷新连接。其他同项目会话在下一次任务前读取新配置；
CLI 在启动时读取配置。

Windows 桌面包已经包含 Python 和 MCP SDK。源码/CLI 环境需要 Python 3.10+ 并安装 `.[mcp]`。
某些第三方本地服务还需要 Node.js/npx、uv/uvx 等环境，按安装卡片提示准备。
HTTP 服务支持可选的 [OAuth 登录、刷新和退出](mcp-oauth.md)，也可手动填写服务支持的请求头；stdio 使用环境变量。OAuth 支持自动注册、客户端元数据文档和用户提供的固定 Client ID / 可选 Secret。Xuloom 本身不需要注册账号；旧版 SSE 暂未实现。

## 配置格式

项目 `.xuloom/mcp_servers.json` 与 CLI 共用：

```json
{
  "mcpServers": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "headers": {},
      "enabled": true
    }
  }
}
```

本地服务使用 `type: "stdio"`，并提供 `command`、字符串数组 `args`、环境变量对象 `env`。
`enabled` 必须是真正的 JSON 布尔值 `true` / `false`，不能写成字符串 `"false"` 或数字 `0`。省略时保持默认启用；市场安装仍显式保存为停用。`type` 省略时，存在 `url` 字段则按 HTTP 校验，否则按 stdio；显式填写空值、未知类型或错误类型会被拒绝，不会退回执行 `command`。HTTP 地址不接受嵌入用户名密码、无效端口、空白或片段；保存配置不会启动程序或发起连接。

手写配置出错时，“我的服务”会显示“配置需修复”；可编辑或移除，不能通过“启用”绕过校验。读取和失败的编辑不会覆盖原文件。挂载 Skill 的 `mcp_servers.json` 出错只跳过有问题的定义，其他有效服务继续加载；界面及 `xuloom mcp list --cwd <目录> --json` 的 `configurationIssues` 会给出清单路径和原因，不回传凭据。CLI 启动时也会打印这些诊断。修复、添加或移除 Skill MCP 清单后，桌面会在下次任务检查中发现变更，也可手动刷新连接。
桌面已保存的请求头和环境变量值不会回传界面；编辑时留空保留，删除字段清除。
Windows 保存时会用当前用户的原生加密保护 `env`、`headers` 和带查询参数的 URL；读取旧明文不改写，下次保存迁移。macOS / Linux 的可选系统凭据存储依赖与限制见[凭据保护](credentials.md)，尚未完成对应系统原生验收。保存、启停、移除和显式迁移共用跨进程写入锁，防止界面与 CLI 的编辑互相覆盖。文件应保持私有，不自动附加到模型上下文；移动配置后重新填写凭据的说明也见该说明。
手动把凭据写入命令参数时，参数会显示在预览中；优先使用请求头或环境变量。

## 内置搜索与 MCP 搜索

内置 `web_search_tool` 和 `web_fetch_tool` 默认启用，模型可直接调用，无需先发现或激活。
Python 3.10+ 使用 DDGS 多搜索源库，不需要搜索 Key 或安装 MCP；旧 Python 3.9 安装保留原兼容库。
搜索在后台线程运行，返回标题、链接和摘要；为空或服务异常会标记失败，停止任务无需等搜索返回。
单次搜索可通过 `max_results` 请求 1–50 条结果，默认 5 条；文献或人物研究可按需增加到 15–30 条。实际条数取决于搜索服务，可能少于请求值；更高上限不能解决限流或网络故障。
公共搜索源可能限流或返回验证页，不能保证始终可用。`web_fetch_tool` 提取静态 HTML 的纯文本，不运行 JavaScript。
查询工具目录支持自然语言关键词，不会再因为整句不匹配误报搜索工具不存在。公网研究应使用网页来源，不能以本地项目文件替代。

搜索 MCP 是另一条独立路径：模型调用外部搜索工具，服务返回结果，模型整理回答。
本地模型也可以使用，前提是推理接口支持工具调用。DDGS 内部会尝试多个搜索源；内置搜索与用户配置的 MCP 之间仍由模型选择，不会静默安装或修改 MCP 配置。
第三方服务的凭据、额度和费用由提供方决定。
