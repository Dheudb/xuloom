## 测试中发现并修复的问题

早期回归暴露：远端导航重新打开时会把草稿附件 ID 清空，已改为保留并向原目标核对；隔离/重定向用户目录没有系统 Downloads 路径时另存为失败，已改为仍可打开文件名形式的保存对话框。原生清单路径需保留 Windows 历史大小写，而版本校验使用规范路径；该差异已修正，并保留旧附件兼容检查。

早期测试程序也有错误：新增 CLI 参数后，旧手工测试参数缺字段使取消用例等待不存在的启动事件；修正了测试参数。两项安装测试模块名最初填写错误，首次 55 项结果包含 2 项导入错误，修正名称后最终 61 项完整通过。可选 CLI 按模块补验还暴露了两个测试文件原先只兼容全量发现目录的导入方式，改为同时支持包内及独立模块入口；第一次 24 项有 2 项导入错误，第二次 47 项有 1 项测试辅助模块导入错误，最终 50 项全部通过，早期日志仍保留。这些调整只涉及测试入口，不改变已验收的产品资源。断言曾错误检查后台记忆请求而非最后流式模型请求，以及把原始 Windows 路径与规范化模型引用直接比较，均已校正。隐藏 Electron 首次截图可能是旧帧，最终等待渲染后重新捕获并实际检查，未将初始空画面算作视觉通过。

这些早期失败有日志保留；未将单次定向成功当作全部验证完成。

## 范围与限制

加密 SSH 服务和模型 HTTP/SSE 服务均为本机隔离测试环境，使用真实系统 OpenSSH 和真实产品执行入口；没有调用用户真实模型/媒体 API，没有读取、修改、上传或打包私人 Taiyi Skill。SSH 测试依赖 Paramiko 仅存在于开发测试环境。

此处不宣称两台物理机器、POSIX/macOS 原生、真实供应商多模态质量和数小时科研任务已经验证。上传以单个文件为提交单位；批量中较早的成功文件可保留。断线后查询保存的 UUID，不自动重放上传或用户任务。所有后续后端、跨平台及整体 UI 审查范围继续见[持续目标](product-roadmap.md)。
