# Windows 凭据保护与配置修复的本地验收

本轮继续执行[持续产品目标](../product-roadmap.md)。实现为当前用户 DPAPI 字段保护，复用原配置文件、原子替换和 OS 写入租约；没有新增常驻服务、模型规划回合、密码学第三方依赖或第二套凭据数据库。原生实现与限制见[凭据保护](../credentials.md)。macOS/Linux 当前仍为 `file-only`，不宣称已接入系统原生存储。

## 行为与故障覆盖

- 模型及生成服务的 API Key，MCP 的 env/headers 和带查询参数的 URL，在 Windows 保存时原生加密；普通读取不改写旧配置。扩展自有的数据和 Schema 不按字段名字擅自改写。
- 解密核对原用户、文件及字段上下文。损坏、未知版本或其他位置的受保护值保留原文；设置仍显示模型与地址，执行、角色连接、模型发现、生成及 MCP 在请求/传输创建前拒绝。
- 验证较长 Unicode 敏感字段、加密失败、原子发布失败及临时文件清理；配置值往返一致，不因失败清空原配置。API Key 的控制字符在 SDK 创建前拒绝，错误不回显该值。
- 正式 CLI 支持 `credentials status/migrate/set-model-key`，修复从指定环境变量取值，不用命令参数传递 Key；同时补齐既有 `sandbox-cleanup` 的正式分发入口。状态/迁移/修复不创建模型请求。
- MCP 保存、启停、移除与迁移共用 OS 租约，进程持锁期间重读再改写；四个真实子进程同时添加服务验证无覆盖。桌面调用放在线程中等待，不阻塞异步事件循环。
- 联调发现生成模型编辑会把新增的只读诊断元数据回传为保存参数，已改为显式构造可写字段并复测。两处旧测试仍要求落盘明文，已改为验证密文及实际使用后的鉴权；没有放宽产品参数校验来适配测试。

## 已取得的证据

- 最终生产代码冻结后，Python 3.12 完整发现 92 个模块、851 项，分两组执行 435/416 项：738 通过、113 条件跳过，零失败/错误；耗时分别 210.099/713.025 秒。日志为忽略目录中的 `credentials-final-shard-0.log` 与 `credentials-final-shard-1.log`，不是早期全量与新增定向测试的拼接。
- 原安装 Python 定向 112 项通过，覆盖凭据、模型目录/网络/实际 SDK、生成、桌面桥、MCP 与输入保存。主进程从原安装导入；17 个 Python 子进程强制隔离启动，清除源码搜索路径，避免包内 CLI 检查误用源码。
- Python 3.9 定向 35 项，34 通过、1 项因可选 MCP SDK 不可用跳过。Node 逻辑 72 项通过；TypeScript/Vite 及 165 个 Python 模块的名称/语法检查通过。
- 实际安装的 Codex、Claude Code、Pi、DSH 六项本地协议/续聊检查通过；端点全部是自有本机夹具，不是远端模型性能证据。
- 源码及更新后原 EXE 的模型、生成服务、MCP 三条隐藏界面流程通过。模型流程额外注入损坏密文，重启后验证地址保留、诊断可见、未发出请求，再重新填写 Key 成功继续。MCP 从加密配置建立真实本机 HTTP 连接，服务器核对实际鉴权；诊断和聊天模型请求不含测试凭据。
- 用户本机已有配置经原安装运行时显式迁移，四个敏感字段受保护、零不可用字段，解密后的配置值完全一致。只输出数量，零模型请求，未扫描其他项目，未另存明文副本。

所有模型调用均指向本地协议夹具；使用独立 HOME、配置、数据目录和隐藏窗口。私人 Skill 不参与打包；更新包仅含九个公开内置技能。本轮未上传代码或更改 GitHub Release。

113 条件跳过延续既有环境边界，主要涉及未启用的外部 CLI、可选浏览器及特定 SSH 组合，另有本机符号链接条件未满足；六项显式启用的实 CLI 协议检查不含跳过，但不代替其余组合或真实供应商验收。

## 本地交付与剩余范围

原启动路径保持 `desktop/release/Xuloom-win32-x64/Xuloom.exe`，构建 `20261102-171249`，正常退出后应用资源更新，保留原回滚资源。175 个 Python/Markdown、62 个前端资源、18 个 Electron 文件与当前源码逐字节一致，EXE SHA-256 保持 `2529b494f4123f152bce346051f7bd855ef95006424a561953cf17c49a3d1ba8`。校对记录为忽略目录 `desktop/build/credentials-final-installed.json`。

这不是操作系统级隔离或同用户宿主代码的秘密隔离，也没有完成 MCP OAuth、其他系统原生凭据后端、签名安装器/自动更新、真实模型长任务及物理跨机验收。旧版本读取协议和配置备份的兼容边界已写入使用说明，不为降级另留明文副本。CI 保持账号计费限制下的手动触发。
