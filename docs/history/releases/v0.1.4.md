# Xuloom v0.1.4

新增“输出与来源”，让一次任务实际写出的文件、搜索返回的链接、读取过的页面和已用工具可以集中回看。

- 桌面聊天右上角打开，支持本轮/整个会话；文件可直接预览，来源通过浏览器打开，工具行跳到活动筛选。
- 本地与 SSH 的正式、交互 CLI 共用已保存记录，查询不调用模型，也不依赖模型 Key。
- 索引沿用现有产物持久化，支持上下文压缩、子代理排队/跟进、中断、重启、分支和编辑；会话移动保留原文件位置。
- 只采用实际成功的工具回执；不从助手文字、网页正文或失败调用中虚构来源。旧记录缺失来源时明确提示。
- 弹窗支持键盘关闭、窄窗口和滚动；修复受侧栏宽度裁切与快速缩窗越界。

没有新增运行依赖、默认提示词或第二套调度器。公开包只有九项内置 Skill，不含私人 Taiyi、用户配置、凭据和历史。继续使用同一 EXE 路径。

接口和边界见 [输出与来源](../../session-summary.md)。分布式原生派发、外部 Agent 后端及生成媒体尚未在本版本实现，继续按 [完整目标](../../product-roadmap.md) 推进。

验证：Python 3.12 最终全量 495 项（494 通过、1 项因 Windows 符号链接权限跳过）；桌面逻辑 64 项和前端构建通过。源码摘要、活动、完整加密 SSH 界面通过；原安装构建 `20261101-161929` 的摘要/完整 SSH 界面及包内 Python/CLI/MCP 34 项通过。所有模型流来自本机协议服务，未消耗远端模型额度，不能替代跨平台原生与真实供应商验收。
