# 按用途配置生成模型的验证（2026-11-02）

版本 `0.1.22`。本轮将图片、视频、语音、音效、音乐作为直接配置入口，每个模型只有 API 地址、Key、模型名。删除界面的连接 ID、服务名称、协议选择、输入字段、下载来源和默认 JSON。旧连接文件仍供已有集成读取，不要求用户迁移或重填 Key。

## 接口与轻量边界

复用 `media_tool`、中央媒体任务回执、文件类型／大小检查、权限、输出来源和播放。没有新增服务、SDK 或常驻调度器。新增两个普通模块负责协议转换和同步／视频结果处理。

新配置自动选择已经适配的标准图片、语音、异步视频接口，fal Queue，或支持的音频接口。选择依据为明确的地址格式、已知协议主机或无凭据的公开 OpenAPI。不会依次向多个生成路径试投，不会失败后切换模型或供应商再收费。不预填供应商不能解释成无需适配任意私有协议；精确支持范围见 [media.md](../media.md)。

统一选项由调用工具的 agent 根据需求填写、适配器转换，不让用户在设置里写 JSON。字段、范围、参考图支持不匹配时在 POST 前报告错误。公开 schema 不执行远程引用、不携带 Key；已配置私有凭据只到该生成服务的相同 API 来源，产物 CDN 下载不附带凭据。

- Python 3.12 相关七模块 75 项通过。最终协议／持久化修正后的 Python 3.9 媒体相关 45 项通过。没有将旧版本的完整回归数量冒充本版本全量结果。
- Node 逻辑测试 72 项通过，TypeScript／Vite 构建通过。
- 隐藏 Electron 源码 E2E 通过：五类空白表单、每个恰好三个输入，无协议、JSON、供应商预填；保存不调用生成服务；Key 隐藏与编辑保留；App／CLI 共用配置；真实 PNG、WAV、VP8/WebM 解码播放；来源导航、直接状态／取消、未发送草稿保留；重启不重提；单模型删除不取消供应商任务。
