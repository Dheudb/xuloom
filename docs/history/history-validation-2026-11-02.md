# 子代理历史查看验收：2026-11-02

范围：0.1.18 的本机原生、Claude Code／Pi／Codex／DSH 和 SSH 子代理只读历史。使用方法及读取上限见[历史接口](../agent-history.md)，完整产品范围继续由[持续目标](../product-roadmap.md)管理。

## 实现与边界

直接读取集中存储的原生 JSON、外部 CLI 的已有 JSONL 及 DSH 不可变图片对象，没有第二套会话数据库、执行状态机或调度器，也没有追加 Agent 提示词或默认运行时依赖。

App 支持完整记录入口、工具／公开推理折叠、复制、懒加载图片、内容绑定的分页、刷新和键盘操作。短记录窗口随内容收缩，长记录内部滚动。正式 CLI 的 `transcript`、`remote transcript` 与本机／SSH 交互终端的 `/history` 复用同一接口；分页游标保留大小写。

读取不调用 `SessionManager.load_subagent_transcript`，不改变正在运行写者的预期版本，不取写者锁、不续跑、不重放工具。SSH 查看从原先冻结的、仍然匹配当前配置的执行主机读取，不把本机同名文件当作远端结果，不传递模型凭据或 worker 控制 token。

系统指令、连接配置及传输事件不作为对话展示；不能还原模型未公开的推理。日志保存顺序不等于新的完成或恢复证明。尚未支持的内容类型和超限记录明确报错或提示，不伪造完整预览。

## 遇到并修正的验证问题

- 初始单元检查使用了不存在的临时目录清理函数名，造成 teardown 错误；改为现有、校验所属目录的 `remove_fixture`，没有放宽功能断言。
- 首个键盘断言把头部关闭按钮误当成最后一个可聚焦元素；改为实际最后元素，验证 Tab 循环、Escape 和焦点返回。
- 首次暂存发现 `setup.py` 仍是旧版本，打包工具明确拒绝，原安装没有应用该不一致资源；同步版本后重新暂存。
- 隐藏 Electron 窗口的 Playwright 页面截图超时，历史内容已经成功读出；截图改用仓库现有 `capturePage(stayHidden, stayAwake)`。人工查看后修正固定高度留白。
- 首次全量缺少浏览器缓存环境变量，按上述方式重跑对应完整分组，保留首次失败，不把未运行的真实浏览器检查算通过。
