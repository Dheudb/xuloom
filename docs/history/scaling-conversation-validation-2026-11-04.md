# Scaling 运行中对话与改向验证（2026-11-04）

## 交付范围

v0.1.29 增加桌面运行详情中的主 agent 对话，以及共用控制端的 CLI `message` / `messages`。入口、工作台标题和首次进入说明标注“实验阶段／开发测试版”。节点模型下拉继续列出对应 API 连接的全部已配置模型。

消息复用本机主协调者的原生会话。普通问答不改目标、不重启 worker；明确改向时由模型生成修订计划，代码负责停止旧工作、确认回执、保留历史并开启下一轮。断线不等于停止，未确认时不能显示新方向已应用。模型输出格式修正最多两次，失败保留原方向与原始执行记录。

消息、回复和运行标记采用原 SQLite WAL 事务。相同请求身份重复提交不重复执行；控制端替换后继续处理已落盘消息。问答可以发生在暂停或已完成的运行中，取消中的运行和已取消的运行拒绝新消息。暂停中问答或改向都不自动恢复探索。

## 验证边界

本轮不调用真实供应商、不连接外部机器，也没有做千级真实模型并发或 macOS／Linux 桌面测试。加密 SSH 回环是本机 SSH 服务与真实 SDK 到本地确定性 SSE 的协议验证；不能替代模型自主调度质量或真实跨机长期运行验收。

对话需等待主会话当前回合结束以保持单写者。多槽位连接保留一个本机协调槽位；单槽位必须由节点确认模型已空闲后临时借用，断连时不强行收回。离线额度仍保留给原运行，不转让给其他运行。该管理范围为 Scaling，不承诺控制其他应用使用同一供应商账户的请求。
