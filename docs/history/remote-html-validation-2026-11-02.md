# 本机与 SSH 网页预览统一验证

源码 `0.1.12`，2026-11-02。[完整目标](../product-roadmap.md)继续有效；本次补齐 SSH HTML 预览及 CLI 资源读取，不代表远端附件、远端截图、外部 CLI 经 SSH 或跨平台已经完成。

## 实现及范围

原入口明确拒绝远端 `preview.open`。现在本机与 SSH 同用 `files.htmlInfo`／`files.htmlChunk`：执行端校验 HTML 入口、真实资源路径、文件类型、30 MB 上限及版本，客户端通过现有 JSONL／SSH 分块读取。原有本机 Electron 文件读取分支被替换，HTML 与音视频复用一个有界流读取函数；无新 SSH 服务、SDK、模型提示词或 Agent 状态机。

页面仍在本机隔离 iframe 内显示，远端文件通过 SSH 提供，不是远端浏览器或任意端口代理。保留原有 CSP、独立随机预览来源、无 Node／桌面桥访问及关闭撤销。隐藏路径、穿越、外部链接资源与未支持类型拒绝；会话确实修改的工作区外 HTML 仅允许单个入口，不能读取邻居文件。文件变化、错误回执或 SSH 断线不会改读本机同名文件。

正式 CLI `remote preview` 可查询入口／资源元数据，或取得带版本、偏移与总大小的 Base64 分块；交互 CLI `/preview` 查询同一接口。客户端组装多段内容时应核对各段版本；直接 RPC 读取必须提供已取得的版本。所有这些读取不调用模型、不自动续跑任务。

后台截图也使用同一资源接口，由所属引擎提供传输；仍限制在已授权本机工作区。远端截图保留原有明确失败行为，未偷偷使用本机浏览器替代远端执行环境。顺带移除未使用导入和未使用局部列表，保留 Skill 的前置读取校验。
