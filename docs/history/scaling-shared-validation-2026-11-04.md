# Scaling 共享协作本地验收（2026-11-04）

v0.1.31 复用 Scaling 的记录表、事件游标和认证 SSH／本机通道，增加同机原子认领、跨机缓存同步、发现／失败摘要及带哈希的产物清单。没有新服务依赖或普通会话提示词。详细契约见 [Scaling](../scaling.md#共享协作离线优先)。

## 已验证

- 24 个真实 SQLite 并发认领，仅一个成功；同一提交重放不启动第二个执行，也不生成重复事件。
- 精确重复任务回执为 `deduplicated`，不是 `completed`，保留原任务和节点引用；独立验证、不同输入版本和明确变体可独立执行。
- 两个隔离节点各自认领同一工作，重连后保留双方记录、显示冲突；缓存到达后新的重复任务被拒绝启动，不反向取消已有执行。
- 同机线程、跨节点增量重放、旧版本回执、冲突版本、来源身份变化、错误运行及错误认证均有定向检查。
- 共享摘要按游标分批进入工具结果，19 条未读记录分 8／8／3 送达；不会为了限制单次注入而丢掉剩余记录。图片工具结果与共享上下文同时存在时，原生图片、持久化引用和 UI 预览继续有效。
- 产物仅从所属任务目录发布；拒绝越界和链接，检测已变更的文件；UTF-8／二进制字节分页经 base64 无损重组，核对 SHA256。通过两个独立 Node 的认证请求路由读取原节点文件，不通过模型转抄内容。
- 模拟供应商网络失败：结束该次执行、保留失败和认领 `needs_review`，不误报成功、不自动重放。已有自治组长的 SSH 断连后继续、重连后汇总测试增加了共享记录同步检查。
- 桌面与 CLI 共用 `scaling.shared` 查询；桌面可搜索和查看详情，较窄窗口无横向越界。包内 CLI 帮助包含 `shared`、`--kind`、`--query` 和 `--entry`。
