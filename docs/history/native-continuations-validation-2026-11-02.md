## 本轮交付

此前 `tool_sequence` 是按需发现后显式调用的工具。本轮补上[原生模型请求边界](../native-continuations.md)：普通工具携带可选动作图，主模型声明字面参数和条件；执行器剥离元数据、提前检查整个计划，再按真实工具回执自动推进。没有计划时保持原循环。

支持条件分支、依赖汇合、独立且可安全并发的只读动作、输入／权限／工具变化时回退、中央检查点恢复及请求替代记录。使用既有授权执行器、会话锁、工具意图和持久化，不新增供应商、选择器模型、Node 运行时或调度服务。App 和 CLI 显示真实子工具及续跑说明，CLI JSON 保留原生事件。

## 请求次数和产品入口

本地 SDK 夹具中，根调用声明两个后续动作，三次实际动作只发生两次主模型请求（声明／根调用、最终回答），中间没有模型或选择器请求。没有声明时，仍按原循环请求模型。

隐藏 App 和非交互 CLI 使用实际本地 HTTP 流服务：一次普通 `file_write_tool` 附带计划，随后另一次真实写入由请求边界自动推进，合计两次模型请求；条件为假的分支不会创建第二个文件。界面可展开查看实际文件工具和“按已声明计划执行”的说明，CLI 可取得 `continuation_substitution` 事件；重开历史不执行动作。测试验证 DOM、交互与文件，没有声称完成截图式全界面视觉审查。

这些夹具能证明原生路径和请求省略，不能证明真实模型会稳定声明计划、任务质量提高或整体费用下降。协议、声明和所有实际模型 usage 继续计费；没有将省略请求虚构为固定 token 收益。
