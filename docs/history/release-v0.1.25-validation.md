# v0.1.25 发布检查

日期：2026-11-03。原 Windows x64 安装资源构建 `20261103-103411`，版本 `0.1.25`。本次修改模型连接设置的布局、说明与版本标识，保留原有配置和执行协议。

基础页集中显示 API 地址、Key 和模型；模型列表按需展开，思考、输入能力、原生搜索及连接选项放入“更多设置”。输入框与按钮统一对齐，表单独立滚动，保存栏固定在底部。展开、收起和保存均保留已有多模型及能力配置。

本地验证：

- 源码版本专项 3 项通过。原安装内 Branding、原生搜索、精简工具目录、发布资源专项 20 项通过。
