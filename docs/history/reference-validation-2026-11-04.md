## 发现与修复

首次成品验证捕获到真实缺陷：隔离 Python 忽略 `PYTHONIOENCODING`，本机交互入口没有像远端入口一样主动选择 UTF-8，部分输出在 GBK 下报错。已在 CLI 入口统一编码；保留原 `-I` 与输出断言，未放宽测试。

早期 GUI 脚本错误地期待打开文件后子代理对话弹层仍常驻；实际弹层随原能力面板卸载而关闭，已更正脚本预期并复验。初次失败日志保留在忽略目录，没有将首轮写成全绿。

记录位于 `desktop/build/reference-*.log`，截图 `desktop/test-results/references-ui.png`。本轮模型响应来自本机协议夹具，没有调用远端模型，没有进行数小时真实模型、其他操作系统或真实跨机的能力排名测试。
