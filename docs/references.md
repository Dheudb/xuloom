# 链接与文件引用

这是展示层能力，不向模型增加指令，不新增模型请求，也不安装额外的运行依赖。桌面和 CLI 的路径解析由同一组跨语言测试用例约束。

## 桌面

- HTTP/HTTPS Markdown 链接与裸网址可打开系统浏览器，支持鼠标、键盘和中键。GitHub 使用本地站点图标，其他网站使用通用网页图标；不请求远端 favicon。
- 文件引用使用 `[说明](docs/report.md)` 或行内代码路径。支持绝对路径、工作区相对路径、目录和无扩展名文件；普通词语不自动变成文件链接。
- 支持 `文件.py:42`、`文件.py:42:3`、`文件.py:42-50`、`文件.py#L42-L50`。打开源码后高亮并滚动到首行；列号定位到该行的字符位置。无效或不存在的行号不妨碍打开原文件；范围表示定位首行，不表示选中整个范围。
- 路径中的空格应使用 Markdown 目标的尖括号形式，或行内代码。字面 `#`、`?` 使用百分号编码；相对链接以当前预览文档所在目录为基准。
- 主回复、执行过程、工具结果、子代理结果与历史复用同一打开入口。工具结果中的图片不自动加载，保留独立的已记录图像入口。
- 路径仍须通过既有的工作区／已记录修改文件校验；不会直接执行 EXE、脚本或 Shell。目录浏览不会扩大到工作区外。无效、删除或越界引用会明确报错。
- SSH 子代理引用先打开已登记的远端会话，再由远端解析和读取。两端需使用支持 `files.reference` 的版本；断线或版本不兼容会报错，不回退读取本机文件。

## CLI

本机和 SSH 交互终端复用 Rich 处理 Markdown。流式输出按完整块渲染，未闭合的链接、引用定义和代码围栏保留到可解析时；不是每个 token 都重绘屏幕。最终相同回复不再重复打印一份。正式 `exec --json` 的事件格式保持不变。

支持 OSC 8 的终端显示可点击网页链接；本机工作区内可核实的文件／目录可显示文件超链接。终端或系统文件处理器是否按 `#L42` 跳转，取决于终端和编辑器，不能保证具备桌面源码预览的定位效果。无法使用超链接时保留可复制地址；可通过 `XULOOM_HYPERLINKS=0` 禁用，或在确认支持时用 `1` 启用。

SSH CLI 不会将远端路径转换成本机 `file://` 地址；保留远端路径文字，可用现有 `/read`、`/files` 读取和浏览。远端网页链接仍可打开浏览器。

自动压缩的开始、完成、失败、取消提示在本机／SSH 交互终端均可见。终端没有桌面的文件预览栏、图像弹层或复制按钮；两端共用执行能力不等于显示方式完全一致。
