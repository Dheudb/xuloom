# Xuloom v0.1.35

下载 `Xuloom-v0.1.35-windows-x64.zip`，完整解压后运行 `Xuloom.exe`。ZIP 包含桌面程序、Python 运行时、MCP SDK 和 9 项公开内置 Skills；GitHub 自动生成的 Source code ZIP 不是应用。`SHA256SUMS.txt` 用于校验完整发行包。

## 本次更新

- 桌面主任务运行时可以追加文字要求，无需先停止。待送达状态、撤回、真正送达后的消息顺序均可见；已开始的操作保留结果，尚未执行的旧调用交回模型重新判断。
- 未送达要求保存于同一会话；停止、关闭、重启后可显式恢复。重复提交同一请求 ID 不重复入队；保存失败明确报告错误，不伪装送达。
- 非交互 CLI 新增 `exec --input-stream` 和 `exec --resume --session`；复用相同引擎、回执、权限和集中历史，不增加默认监督模型或默认提示词。
- 一并发布此前本地维护改进：按需加载模型 SDK、轻量 help 路径、扩展与恢复检查、版本/验证信息，以及 Scaling 配置加载期间可立即打开添加表单的修复。

使用说明：[运行中追加指令](../live-input.md)。普通交互式 TTY 暂未增加运行中行编辑。补充文字不会跳过审批、强行打断任意外部进程，或自动替换持续目标的验收条件。

## 支持与验证范围

桌面发行包支持 Windows x64。CLI 使用同一 Python 引擎；macOS/Linux 桌面成品、系统级隔离及真实跨机长任务仍属独立验证范围。Scaling 为实验功能。

本轮验收使用本地确定性模型、回环 HTTP 和隐藏 Electron 窗口，不调用远端模型，也不证明真实模型长任务成功率。发行包中的构建记录绑定源码提交、构建号、资源哈希和实际测试结果；可在“设置 → 工作区 → 程序版本与验证”查看。历史验收仅适用于各自记录的版本。

没有上传用户 Key、会话记录或私人 Taiyi Skill。更新沿用原 EXE 路径并保留资源回退备份；当前仍为便携 ZIP，没有签名安装器或用户端自动更新。
