# Xuloom v0.1.36

本次只精简 Windows 分发和资源更新，保留 Python 引擎及全部运行依赖，不增加用户安装步骤。

- 从发行包中移出明确列出的编译开发资源、依赖测试/示例和开发帮助；缓存不随包分发。
- 保留原 EXE、全部运行 DLL、语言资源、证书、许可证及模型 SDK；PDF、图像、MCP、凭据和后台截图继续自带依赖。
- 精简原安装时先校验文件，再移入资源回退备份；更新失败恢复已移动的内容。配置、Key、会话和私人 Skill 不参与清理。
- 完整程序包仍使用 Windows 可直接解压的标准 ZIP，并提高 Deflate 压缩率。可选压缩工具仅用于构建，不随应用分发。

详见[体积和安全边界](../packaging-size.md)。源码、原安装和完整 ZIP 的构建记录对应同一提交。最终下载大小、与上一版的比较及实际测试结果见 Release 发布说明和随包验证记录。

Windows x64 桌面仍为完整便携包；请完整解压后运行 `Xuloom.exe`。macOS/Linux 桌面成品和真实远端模型长任务不在本次验收范围，Scaling 继续标注为实验功能。没有上传用户凭据、会话或私人 Taiyi Skill。
