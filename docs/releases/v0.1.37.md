# Xuloom v0.1.37

修复 Ultra 决策协议和子代理完整历史读取，沿用现有执行、权限、排队和持久化机制。

- Ultra 优先通过原生 `collaboration_decision` 工具参数传输结构化决策，兼容完整的旧 JSON 决策；验证完成前不执行工作工具，不把错误文本当成成功决策。
- 已过期的 Ultra 格式纠错指令不再进入正常执行或新用户回合的模型请求。诊断历史仍保留，不删除用户消息。
- 子代理检查点统一保存代理和所属会话身份，修复运行中查看完整历史时误报 `Agent receipt is missing or belongs to another conversation`。旧检查点可依据其已保存的身份只读展示，跨会话或身份冲突仍拒绝读取。
- 桌面和 CLI 复用相同修复，不增加后台监督模型、独立调度器或额外持久状态；简单对话仍可在一次决策请求中返回，不为凑数量派发子代理。

本地回归覆盖原生决策、错误修正、并行工作和全部汇合、运行中与完成后的历史查看、取消及重启恢复。实际验证数量和程序构建号见 Release 发布说明及包内验证记录。

本次未调用远端模型，不承诺任何特定模型的真实长任务成功率，也不把 Ultra 等同于每次回答必定联网。Windows x64 程序保持完整便携 ZIP，完整解压后运行 `Xuloom.exe`，用户无需另装 Python。macOS/Linux 桌面成品未纳入本次验证，Scaling 继续为实验功能。私人 Taiyi Skill、用户配置、凭据及聊天记录不随源码或程序发布。
