# Xuloom v0.1.3

原生子代理权限与工作目录修复。本版本不增加运行依赖、第二套调度器或默认系统提示词。

- 子代理执行工具时应用父会话的当前拒绝、询问及 Plan 限制；不继承父会话的临时授权。跟进和重启恢复保留自己的拒绝规则。
- 引擎实例的工作目录同时用于项目指令、权限、Hooks、记忆、Git 与工作区副本，不再意外使用宿主进程目录。
- 文件和命令目录在授权前解析；审批展示与实际目标一致。工作区副本不再误重定向名字相近的兄弟目录。
- 移除记忆模块中重复、默认加载 `CLAUDE.md` 的旧路径。明确开启兼容选项时由现有指令加载器读取一次。

桌面和 CLI 共用以上修复。公开包只包含九项内置 Skill，不含私人 Taiyi、模型凭据或用户历史。

验证：Python 3.12 全量 478 项（477 通过、1 项因 Windows 符号链接权限跳过）；桌面逻辑 64 项、前端构建、源码及原安装的权限/框架 E2E、包内 Python/正式 CLI 30 项通过。原安装构建 `20261101-152247`。测试使用本地协议流和加密 SSH 回环，没有消耗真实模型额度；不代表跨平台原生或真实模型长任务已验收。

发布状态见 [开发者审查记录](../developer-base-audit.md)；SSH 分布式派发、外部 Agent 后端、生成媒体和完整 UI 审查仍按 [持续目标](../product-roadmap.md) 推进，不属于本次已完成能力。
