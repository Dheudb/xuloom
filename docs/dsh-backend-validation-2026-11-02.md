# DSH 后端验证（2026-11-02）

本轮为 `0.1.16`：复用现有角色、队列、权限、模型连接、预算、存储及取消入口。通过实际安装的 `@deepseek-ai/dsh 0.2.1-rc.5`／headless、Node `24.14.0` 和本地 HTTP/SSE/MCP 检查；未使用个人 DSH 登录、真实模型供应商或付费额度。该程序只装在开发测试目录，默认产品不包含它、Node 或它的依赖。

## 原始依据与实现边界

读取了官方 [headless 文档与实现](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/bundle/headless)、安装包的实际 CLI、profile、MCP 和 JSONL 持久化代码。npm 已发布版本的 `final` 不含开发版新增的全部字段，实际检查使用它的 session／turn/end、退出状态与完整 v4 历史，不假定开发版 Schema 已经发布。

独立最小 profile 不挂载 base bundle、个人配置或遥测插件；仅加载原生执行、模型、压缩、会话／图像存储和受控 MCP 所需服务。没有另一套调度器、模型身份提示或常驻第三方服务。供应商 Key 留在 Python 连接，临时令牌在清理时删除。外部进程工作目录为中央产物的所属目录，工具继续使用 Xuloom 角色实际工作目录，避免 DSH 启动器读取项目 `.env`。

正常完成和跟进会逐项核对完整原生历史、连续序号、所属 Session／turn、已确认文件前缀、最终文字及工具回执。不会把 DSH 的 8 kB 过程投影当成全文。历史和图片引用先做所有者目录校验，目录链接不能重新定义所有者根；图片规范化后核对不可变对象的真实字节与摘要，大小超限不偷偷缩图。初始图片任务明确不支持，模型调用前拒绝。

## 已完成的源码专项

`tests/test_dsh_agents.py` 的 20 项检查通过：两种模型协议、正常跨进程续聊、原生身份／预算／回执、工具图片、继承拒绝、故障工具、供应商未完成流、未知原生工具、取消不重放、历史篡改、最终历史故障、长回答、项目环境／Node 启动参数隔离、初始媒体输入拒绝、图像像素与分辨率、文本投影及越界文件／目录链接。另补公共长路径输入清理、深目录准备及 Windows 过长进程目录的启动前拒绝。共享存储回归还覆盖深数据目录下的会话、子代理历史、记忆和真实 OS 单写者锁，29 项 DSH／存储检查通过。随后冻结运行时代码进行最终全量回归。

源码 App 和正式 CLI 使用同一个实际 DSH worker，验证一次发现后在 App 与 CLI 继续、重启恢复、真实身份、未选工具隐藏、原生回执与桌面创建 DSH 角色。共享 Claude／Pi／OpenAI MCP 边界的 18 项定向回归通过。源码构建通过；原有 JS 大块体积提示仍存在。

## 初轮问题与修复

- 第一轮测试错用普通 Path 检查 Windows 超长历史路径，以及把 `tool_result.is_error` 写在错误层级；改用现有 IOPath 与真实字段后复验。未以不存在的普通短路径推断历史丢失。
- 图片校验先暴露调用既有预览函数的参数错误，再确认 DSH 会转换灰度 PNG。现已在受控桥中明确进行保留分辨率的 PNG 规范化，并对真实原生图片对象对账；未关闭图片验证来换取成功。
- 取消测试曾把接入 API 的“成功取得执行回执”误当成任务成功；实际回执已经是 `external_outcome_unknown` 且无新模型调用，现断言真实执行原因。
- 首轮 App 测试使用了不存在的设置标签，随后错误诊断尝试默认历史路径并得到 ENOENT；现使用实际 Subagents 标签，并移除可能读取默认个人路径的错误诊断。完整 App／CLI 流程已重新通过。

- 后续真实深路径故障注入发现公共临时文件清理会漏掉长路径，中央初始化、会话读写和记忆也有普通路径边界。统一复用现有 IOPath 后，312 字符临时连接文件确实删除，深目录的持久化与锁回归通过。Windows CreateProcess 当前目录另有长度限制，DSH 现启动前明确拒绝，不发模型请求，不伪装已支持。
- 独立连接／密钥轮换与两个实际 DSH worker 并发实测通过；加密系统 OpenSSH 回环的 DSH worker 读到远端证据、使用远端连接并保留同一 Session 续聊。初次 SSH 断言写错大小写、临时测试目录清理未使用长路径，保留失败日志；修正测试后完整流程与精确所属目录清理通过，没有终止用户进程。

- 单进程全量 705 项曾出现 13 错误、3 失败、1 跳过：长路径类型的 Windows 扩展前缀进入只读摘要的归属校验，影响摘要、媒体与 SSH 摘要；一项记忆故障注入仍针对旧 open 入口。现对外恢复普通逻辑路径，在安全读取边界统一规范化并保留 IOPath 读写；调整真实读取故障入口，同时补深目录摘要回归。失败日志保留，最终验收重新覆盖全部发现模块，不能用此前局部通过替代。
