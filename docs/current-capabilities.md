# 当前能力与支持边界

本表是当前源码的能力索引。配置说明链接解释用法；[历史记录](history/README.md)只证明对应日期、提交和环境的结果。具体程序通过了哪些检查，以“设置 → 工作区 → 程序版本与验证”和发行包的构建记录为准。

| 能力 | 默认行为与使用条件 | 当前边界 |
| --- | --- | --- |
| Windows 桌面、CLI | 同一引擎、回执和集中历史；独立会话拥有独立目录 | 桌面成品仅 Windows x64；Linux/macOS 源码 CLI 的兼容检查不等于跨平台成品验收 |
| 模型连接 | API 连接目录共享；桌面模型与推理强度按会话保存，切换不影响其他会话；支持 OpenAI 兼容 Chat Completions、条件支持 Responses、Anthropic Messages | 新会话继承最近显式选择的模型、推理强度、权限与协作档位；打开旧历史不改新会话偏好；删除连接后回退到有效配置。兼容地址不保证任意模型的工具、图片、思考字段都可用 |
| 普通问答 | 按任务需要使用工具；Auto / Solo 没有强制 Router 或监督模型 | 重试、上下文压缩、记忆提取可能增加模型调用；不能承诺每次任务只请求一次 |
| 协作 | Solo 禁止委派；Auto 按需；原生 Ultra 首先通过工具选择简单直答或工作计划，代码派发计划中的搜索和独立任务；结果收齐后汇总 | 复用主模型和执行记录，无独立 Router；简单任务可一次请求结束，复杂任务增加一次计划往返；不保证模型语义分类总正确。外部 Agent／受限角色沿用其可用工具策略；数量不是成功标准 |
| 推理状态 | Chat 与 Responses 复用等待、思考、输出、完成和中断事件；有接口报告时展示推理 Token 或推理条目数 | Ultra 与思考强度独立；没有可见摘要不等于没有推理。流片段数不是 Token，不展示加密推理内容；工具可用不保证模型会调用 |
| Skills / Subagents / MCP | 图形设置与配置目录共用；按需发现工具 | 第三方 MCP 可需要自备环境；依赖存在不等于连接成功；私人 Skill 不随公开包分发 |
| 文件、命令、搜索 | 生产入口校验参数、授权，保存回执；长结果按现有入口读取 | API、网页权限、限流、外部进程和工具依赖可能失败；未知副作用不能自动重放 |
| 后台任务与交流 | 桌面运行中可追加文字、撤回待送达消息；CLI 输入流和程序 API 复用同一会话队列；可向 worker 发消息 | 在模型响应/工具步骤结束后的安全边界送达，不强制打断工具；停止重启后需显式恢复。普通交互式 TTY 暂无运行中行编辑，见[运行中追加指令](live-input.md) |
| 失败、取消、恢复 | 完成与保存分别检查；单写者锁和检查点版本校验；未知状态保留 | 取消请求不等于任意外部服务已经取消；断线、崩溃或未知结果需核对回执；不保证外部系统 exactly-once |
| 记忆与上下文 | 近期上下文、归档、压缩和领域中立摘要；压缩状态可见 | 摘要不是无损副本，原文需按归档入口读取；模型提取会消耗额度，且不等于科学验收 |
| 开发者扩展 | [公开方法与仓库外示例](extensions.md)：工具注册、能力事件、流事件、取消、恢复；兼容模型端点 | 不承诺任意 Python 模型 SDK 可直接注册；自定义 Python 工具与宿主同权，不是安全沙箱插件 |
| SSH / 外部 Agent | 显式配置后使用现有协议、生命周期与回执 | 外部 CLI 须在执行主机安装；回环测试不等于物理两机、所有版本和断线组合全部可靠 |
| Scaling | 独立入口、显式确认高用量、多节点/本机协作 | **实验阶段**；普通会话不启动其控制器；不宣称千级/万级真实模型生产验收完成 |
| 媒体、浏览器 | 用户配置生成模型；浏览器按需启动，桌面可复用 Chromium | 真实供应商生成效果、费用与支持协议由实际服务决定；CLI 浏览器可能需安装可选环境 |
| 权限与隔离 | 审批、工作区隔离、实验性的系统执行后端分别配置 | worktree/副本不等于 OS 沙箱；跨平台强隔离和跨平台桌面分发继续单独验收 |
| 分发与升级 | 完整 ZIP、固定 EXE 路径、资源校验、退出后替换、回滚备份 | 当前没有签名安装器和自动更新；删除便携程序目录保留分离的配置、凭据和历史，不等于清除个人数据 |

科研、写作、数据分析和编程均可通过同一工具与 Skill 接口执行。基座“按协议执行结束且结果已保存”不代表领域结果已达标；领域验收由应用或用户定义。
