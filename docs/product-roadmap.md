- 复用 QueryEngine、原生子代理生命周期、权限入口、中央历史、工具发现与媒体产物存档。可选功能按需加载，不把所有工具说明注入默认对话。
- SSH 优先复用用户系统 OpenSSH 与已有主机配置；校验目标和主机身份，不把密码或私钥拷贝进聊天/工作区。远端运行现有引擎，避免两套执行循环。
- 媒体以薄供应商适配器接入，不打包本地推理框架、图像/视频模型或大量 SDK。供应商字段由能力描述决定，不用“兼容 API”掩盖接口差异。
- 异步媒体任务尽量复用现有执行记录和延迟唤醒，提交、完成、保存、展示分别有可信状态；不让主模型靠长时间空等维持任务。
- 图形界面与 CLI 同时有可测试的生产入口，共享配置、会话和执行契约。用户不必为新增功能手工改源码。
- 私人 Taiyi Skill 保持外部私有；不得进入 Git、内置资源或 Release。API Key、SSH 凭据和聊天记录同样排除。

## 验收与实施顺序

先关闭已复现的权限缺口；随后推进 Git/聊天导航与公开扩展接口，再实现异构角色和 SSH 远端协调，接入媒体适配与产物 UI，同时持续做全界面与无效代码审查。此顺序不删除任何追加要求。

每项至少覆盖：配置与发现、一次正常执行、参数错误、缺失依赖、显式拒绝、取消/断线、重启恢复、保存失败和 UI/CLI 一致性。SSH 要区分传输仿真与真实 SSH 验证；媒体要区分本地协议测试和真实供应商验收。按此前用户要求，当前不调用远端模型、不使用私人 Key 做付费或耗额度验收。真实连接尚不可用时如实记录未验证，不能把模拟测试算作真实供应商成功。
